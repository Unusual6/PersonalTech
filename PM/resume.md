# AI Agent 项目中的 Skill 设计

## 一、Skill 的定位

Skill 的核心作用是将科研实验中的专业操作经验、设备使用规范和任务执行方法，封装成 Agent 可以按需调用的可复用能力。

Skill 不只是 Markdown 文档，也不应该简单地将每个 API 包装成一个 Skill。更有价值的是将一类相对完整的任务处理能力进行模块化封装。

## 二、Skill 能力模块设计

### 1. 设备连接与状态检查 Skill

解决 Agent 不知道设备是否在线、是否满足执行条件的问题。

- 设备连接与初始化
- 查询设备在线状态、运行状态
- 检查耗材、运行环境及设备参数
- 异常状态识别与处理建议

示例：连接 Opentrons Flex，检查设备是否在线、运行环境是否就绪。

### 2. 实验流程执行 Skill

将常见实验操作封装为可复用的执行能力。

- 实验步骤解析与执行顺序组织
- 设备及工具选择
- 实验参数校验
- 执行前确认与异常中断
- 执行结果回传

示例：根据实验目标组织移液、混匀、孵育等操作。

### 3. 实验数据分析 Skill

让 Agent 能够调用标准化的数据处理方法。

- 实验数据读取与格式检查
- 数据清洗与异常值识别
- 指标计算与结果分析
- 图表生成与结果摘要

示例：读取实验数据，计算产率并识别异常实验结果。

### 4. 实验参数优化 Skill

将贝叶斯优化（BO）等算法能力封装成可调用的任务能力。

- 获取历史实验数据
- 确定参数范围与优化目标
- 调用 BO 算法生成候选参数
- 根据实验结果更新优化模型
- 判断是否达到收敛条件

示例：根据历史实验产率，推荐下一轮实验参数。

### 5. 实验任务管理 Skill

处理跨步骤任务中的状态与异常。

- 任务状态查询
- 执行进度跟踪
- 失败原因识别
- 暂停、恢复及终止
- 执行记录与结果归档

示例：实验设备执行失败后，定位失败步骤并决定是否恢复执行。

---

## 三、Skill 内部功能设计

每个 Skill 可以包含以下核心模块：

| 模块 | 主要功能 | 示例 |
|---|---|---|
| 触发条件 | 判断什么情况下调用 | 用户要求执行移液实验 |
| 输入参数 | 定义需要哪些信息 | 设备 ID、体积、孔位 |
| 前置条件 | 检查执行条件 | 设备在线、参数合法 |
| 执行指令 | 描述任务执行步骤 | 初始化、连接、执行移液 |
| 工具依赖 | 关联外部工具 | MCP Tool、API、Python |
| 安全规则 | 规定限制及确认节点 | 超出参数范围禁止执行 |
| 输出规范 | 规定结果返回格式 | 执行状态、耗时、实验结果 |
| 异常处理 | 定义失败后的处理方式 | 重试、暂停、人工介入 |

## 四、Skill 在 Agent 中的调用流程

以用户提出“帮我执行一轮实验，根据历史数据优化实验参数”为例：

1. **用户输入实验目标**
   - 接收自然语言任务描述。

2. **Agent 意图识别与任务规划**
   - 识别实验任务。
   - 拆解执行步骤。
   - 确定所需能力及工具。

3. **Skill 匹配与动态加载**
   - 根据任务需求匹配设备检查 Skill。
   - 加载参数优化 Skill。
   - 加载实验执行 Skill。
   - 加载数据分析 Skill。

4. **LangGraph 组织执行流程**
   - 根据任务依赖关系组织执行节点。
   - 调度 Skill 和 MCP 工具。
   - 管理任务状态及节点流转。

5. **人工确认与安全校验**
   - 确认实验流程。
   - 校验关键实验参数。
   - 检查设备状态。
   - 对高风险操作设置人工确认节点。

6. **外部工具调用与设备执行**
   - 通过 MCP、API、MQTT 调用外部系统及实验设备。
   - 实时接收设备状态。
   - 处理执行异常。

7. **实验结果分析与交付**
   - 分析实验结果。
   - 展示执行状态及结果。
   - 归档实验数据。
   - 将结果反馈给参数优化模块。

## 五、Skill、MCP、LangGraph 的职责划分

| 技术组件 | 核心职责 | 解决的问题 |
|---|---|---|
| Skill | 封装任务能力、操作规范和执行方法 | Agent 在什么场景下、按照什么规则使用工具 |
| MCP | 提供标准化的外部工具调用接口 | Agent 如何调用外部系统和设备能力 |
| LangGraph | 组织工作流节点、任务流转及状态管理 | 多个任务节点如何协同执行、暂停和恢复 |

三者相互配合，而不是互相替代：

- Skill 负责能力组织与复用。
- MCP 负责工具接入与调用。
- LangGraph 负责工作流编排与执行控制。
